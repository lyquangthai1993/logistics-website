# GitHub Submodule & PR Ops Plugin (`github-submodule-ops`)

Packages the 3-repository Git Submodule workflow (`root`, `backend/`, `frontend/`), `gh` CLI Pull Request lifecycle (`RULE-GIT-TASK-WORKFLOW-01`), and branch alignment checks into a single toggleable unit.

## Included Components
- **Skill**: `submodule-pr-lifecycle` (`skills/submodule-pr-lifecycle/SKILL.md`)
- **Rules**: `rules/AGENTS.md` (3-repo submodule discipline, base-from-`dev` mandate, non-blocking git execution)
