# n8n & Telegram Task Orchestrator Plugin (`n8n-telegram-automation`)

Bundles skills and operational invariants for the **n8n Automation Engine** (`https://n8n-automation-production-d298.up.railway.app`) and the **Telegram Bot FIFO Task Runner** (`tools/telegram-task-runner/`).

## Included Components
- **Skill**: `n8n-telegram-ops` (`skills/n8n-telegram-ops/SKILL.md`)
- **Rules**: `rules/AGENTS.md` (Zero Mid-Execution Cancellation, 2-Tier Quality Gate reporting, non-blocking DB queries)
