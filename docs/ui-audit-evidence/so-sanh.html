5 Trọng tâm Tối ưu Đã thực hiện cho Vận hành kho & Điều phối

🛡️ Checkbox Chuẩn Hóa

Thay thế toàn bộ native HTML checkbox bằng Shadcn/Radix UI: có focus ring rõ ràng, kiểm soát trạng thái chính xác.

🎯 Touch Target ≥ 26–32px

Nút mở dòng bảng kho, mã chuyến, mã đơn, preset lọc ngày đều nâng lên ≥ 26px - 32px, chống bấm hụt trên tablet kho.

🧹 Triệt Tiêu Emoji Thừa

Loại bỏ hoàn toàn các emoji rác (🚛, 🚚, 💡, ⚠️, 👋) trong bảng và nhãn; chuyển sang vector icon Tabler sắc nét.

📏 Thanh Cuộn Bảng 4px

Thanh cuộn bảng kê thu hẹp từ 10px xuống 4px bo góc hiện đại, triệt tiêu tình trạng che mất dữ liệu dòng cuối.

📐 UI Compact Density

Thu gọn padding modal kiểm đếm/tiếp nhận từ p-5, p-6 về p-2.5, tăng số dòng hàng nhìn thấy cùng lúc.
